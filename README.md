# Homebrew tap

```sh
brew install --cask eruban/tap/k5k1-prog
```

[K5K1 Prog](https://github.com/ERuban/k5k1prog-mac): back up, restore and flash Quansheng
UV-K5 / UV-K5 V3 / UV-K1 radios on macOS.

`brew upgrade` installs new versions. The cask follows the latest release by itself
(`.github/workflows/bump.yml`, every 3 hours or `gh workflow run bump.yml -R ERuban/homebrew-tap`).
